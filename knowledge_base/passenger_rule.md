# 公交客流异常处理规则


## 一、适用场景

当公交线路出现乘客数量明显增加、
站点上下客压力增大、
车辆承载能力不足时，
需要进行客流异常分析。


## 二、客流分析指标


主要关注：

1. 站点上下客数量；
2. 线路客流变化趋势；
3. 高峰时段客流分布；
4. 车辆运行间隔。


## 三、异常情况判断


### 1. 持续高客流

如果多个时间窗口内：

- 客流持续增加；
- 部分站点上下客集中；
- 当前车辆无法满足需求；

可能存在运力不足。


### 2. 站点拥堵

重点分析：

- 高客流站点；
- 上下客集中区域；
- 车辆停靠时间。


## 四、调度优化措施


根据客流情况，可以采取：

1. 调整发车间隔；
2. 增加车辆投入；
3. 优化线路运行方案；
4. 调整重点站点运力。


## 五、数据结合原则


客流分析不能单独进行。

需要结合：

- GPS运行数据；
- 车辆速度数据；
- 历史运营数据；

综合判断线路运行状态。

# 公交线路低速运行处理规则


## 一、适用场景

当公交线路实时运行过程中出现平均速度持续下降，
或者多个连续时间窗口内速度低于正常运行水平时，
需要启动低速运行分析流程。


## 二、异常判断原则

公交线路低速判断不能仅依据单个GPS数据点。

调度人员需要结合：

1. 连续时间窗口速度变化趋势；
2. 车辆当前位置；
3. 道路交通状态；
4. 历史运行情况；

综合判断线路是否存在运行异常。


## 三、主要影响因素


### 1. 道路拥堵影响

高峰时段、重点路段可能导致车辆平均速度下降。

需要结合：

- 车辆位置分布；
- 历史拥堵情况；
- 同线路其他车辆运行状态；

判断是否属于正常拥堵。


### 2. 临时施工影响

道路施工、交通管制可能造成：

- 行驶速度降低；
- 行驶时间增加；
- 局部线路运行异常。


### 3. 车辆运行状态

需要检查：

- 车辆是否存在异常停车；
- GPS轨迹是否正常；
- 是否存在车辆故障。


### 4. 客流变化影响

高峰时期客流增加可能导致：

- 站点停靠时间增加；
- 发车间隔变化；
- 整体运行速度下降。


## 四、处理建议


当发现持续低速线路时：

1. 查询实时运行数据；
2. 分析历史速度趋势；
3. 结合GPS轨迹定位异常区域；
4. 查看客流变化情况；
5. 根据原因制定调度措施。


## 五、注意事项

不能仅根据单个时间窗口低速结果，
直接判断线路异常。

需要结合多个维度数据进行综合分析。
